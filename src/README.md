# Profile asset generators

The animated SVGs in `../assets` are generated by these scripts. Text is converted to vector paths so the
lettering looks the same on every machine.

```bash
python3 -m venv .venv && .venv/bin/pip install fonttools
cd src
../.venv/bin/python hero.py      # assets/hero.svg
../.venv/bin/python ibuild.py    # assets/i-build-line.svg
../.venv/bin/python line.py      # assets/keywords-line.svg
../.venv/bin/python thin.py      # assets/sakura-divider.svg, assets/quote-line.svg
../.venv/bin/python strip.py     # assets/cats-strip.svg
```

The Japanese glyphs use Noto Serif CJK from the system (`/usr/share/fonts/opentype/noto`).
